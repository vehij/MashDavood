# نصب روی ویندوز — و هشدارهای مرورگر و Defender

خلاصه‌ی صادقانه: فایل‌های ویندوزی مش داوود **امضای دیجیتال (code signing) ندارند**.
هر فایل اجرایی امضانشده و تازه‌منتشرشده از نظر Chrome و SmartScreen «ناشناس» است و
هشدار می‌گیرد — این ربطی به محتوای برنامه ندارد و برای هر پروژه‌ی متن‌باز تازه‌ای پیش می‌آید.
سورس کامل همین‌جاست و فایل‌ها را خود GitHub Actions از همین سورس می‌سازد.

---

## کدام فایل را دانلود کنم؟

| فایل | برای چه کسی | نکته |
|---|---|---|
| `MashDavood-<v>-x64-Setup.exe` | اکثر کاربران (ویندوز ۶۴ بیتی) | نصب‌کننده، شورتکات و ثبت `.md` |
| `MashDavood-<v>-x64.zip` | اگر مرورگر جلوی `.exe` را گرفت | **کمتر از همه هشدار می‌گیرد** — اکسترکت کنید و `MashDavood.exe` را اجرا کنید |
| `MashDavood-<v>-x64-Portable.exe` | اجرای بدون نصب | تک‌فایل، خودش را در temp باز می‌کند |
| `MashDavood-<v>-arm64-Setup.exe` | ویندوز روی ARM (Surface Pro X و…) | |

اگر مرورگرتان سخت‌گیر است، **مسیر پیشنهادی: فایل `.zip`**. مرورگرها به `.exe` خیلی
حساس‌ترند تا به یک آرشیو.

---

## ۱) مرورگر می‌گوید «این فایل خطرناک است» و حذفش می‌کند

**Chrome**: در نوار پایین یا پنل Downloads، کنار فایل روی ⋮ (یا فلش) بزنید →
**Keep / نگه داشتن** → اگر پرسید **Keep anyway**.
اگر فایل را پاک کرده، دوباره دانلود کنید و قبل از بسته‌شدن پنل، Keep را بزنید.

**Edge**: پنل Downloads → روی فایل کلیک راست → **Keep** → **Show more** → **Keep anyway**.

**Firefox**: پنل دانلودها → کلیک راست روی فایل → **Allow download**.

اگر باز هم نشد: فایل `.zip` را دانلود کنید (تقریباً همیشه بدون هشدار رد می‌شود).

### مطمئن شوم فایل دستکاری نشده؟

در هر Release فایل `SHA256SUMS-Windows.txt` هست. در PowerShell:

```powershell
Get-FileHash .\MashDavood-1.0.1-x64-Setup.exe -Algorithm SHA256
```

خروجی باید با مقدار داخل آن فایل یکی باشد.

## ۲) SmartScreen موقع اجرا: «Windows protected your PC»

روی **More info** بزنید → دکمه **Run anyway** ظاهر می‌شود.
(اگر More info را نزنید فقط دکمه Don't run دیده می‌شود.)

---

## ۳) نصب شد ولی آیکون ندارد و می‌گوید «فایل پیدا نشد»

این یعنی بعد از نصب، فایل اجرایی برنامه از روی دیسک **حذف شده** — معمولاً کار
Microsoft Defender است که در سکوت آن را قرنطینه کرده. شورتکات می‌ماند ولی به جایی
اشاره نمی‌کند، پس نه آیکون دارد نه باز می‌شود.

**راه حل:**

1. **Windows Security** را باز کنید → **Virus & threat protection** →
   **Protection history**.
2. آیتم مربوط به MashDavood را پیدا کنید → **Actions** → **Allow on device** / **Restore**.
3. برنامه را دوباره نصب کنید.

اگر باز هم تکرار شد، قبل از نصب یک استثنا اضافه کنید:
**Virus & threat protection settings** → **Manage settings** → **Exclusions** →
**Add an exclusion** → **Folder** → مسیر نصب:
`%LOCALAPPDATA%\Programs\MashDavood`

> در نسخه ۱.۰.۰ یک باگ واقعی هم در همین ناحیه بود: فایل آیکون `.ico` با فریم‌های
> PNG ساخته شده بود و آیکون نوع فایل `.md` هم فرمت مک (`.icns`) بود؛ نصب‌کننده سر
> آیکون خطا می‌داد و شورتکات ناقص می‌ساخت. این از نسخه **۱.۰.۱** رفع شده است.

---

## ۴) گزارش false positive

اگر Defender یا آنتی‌ویروس دیگری فایل را بدافزار اعلام کرد، گزارش‌دادنش به رفع آن
برای همه کمک می‌کند:

- مایکروسافت: <https://www.microsoft.com/en-us/wdsi/filesubmission>
- بررسی چندموتوره: فایل را در <https://www.virustotal.com> آپلود کنید

---

## چرا امضا نمی‌کنید؟

امضای ویندوز نیازمند گواهی code signing است:

- **Azure Trusted Signing** — حدود ۱۰ دلار در ماه، سریع‌ترین راه رسمی
- **SignPath.io** — برای پروژه‌های متن‌باز رایگان است (این پروژه واجد شرایط است)
- گواهی OV/EV از CA — سالانه چند صد دلار

اگر گواهی تهیه شد، فقط کافی است `WIN_CSC_LINK` و `WIN_CSC_KEY_PASSWORD` به‌عنوان
secret به ریپو اضافه شود؛ ورک‌فلوی موجود بدون تغییر دیگری امضا را انجام می‌دهد و
هر دو هشدار بالا از بین می‌رود.
